# Interventions

This folder contains TBsim's interventions, as Starsim v4 products and deliveries (so they run under every solver).

- `care.py` -- Tests (`test`, `Xpert`, `OralSwab`, `FujiLAM`, `CAD`), treatment regimens (`regimens`, `regimen`), and the care cascade (`care`: seeking care, testing, and starting treatment)
- `prevention.py` -- BCG vaccination (`BCG`, an `ss.Vaccine`) and TB preventive therapy (`TPT`, an `ss.Treatment`)
